# Security policy

## Project status and supported use

CAI-EXPERT-LAB is a research/reference project, not a production security
boundary or a supported operational security product. The repository license
limits use; operational, production, or commercial use requires prior written
authorization as stated in `LICENSE.md`. No service-level commitment or
response-time guarantee is made by this policy.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue,
pull request, discussion, or commit.

1. If GitHub's **Report a vulnerability** option is available on this
   repository, use it to create a private security advisory and include the
   affected commit, component, impact, and minimal reproduction steps.
2. If that private reporting option is unavailable, contact the repository
   owner through the contact method listed on the owner's GitHub profile.
   Do not send secrets, personal data, or operational environment data that
   are not necessary to reproduce the issue.
3. The maintainer will acknowledge and triage reports when available, coordinate
   any disclosure with the reporter, and document the disposition. This project
   does not promise a response or remediation deadline.

The repository owner must enable and periodically verify GitHub private
vulnerability reporting and maintain a monitored contact route. The presence
of this file alone does not prove that either route is enabled or monitored.

## Scope and handling

Reports should concern security defects in code or repository-controlled
configuration. Please distinguish a confirmed defect from a limitation already
documented in the project. Do not test against systems or environments that
you do not own or have explicit permission to assess.

# CAI-EXPERT-LAB — Coding Agent Instructions

**Status: PROPOSED / pending human approval.**

All agents, including ChatGPT-connected coding agents and other compatible assistants, must read `AI-GOVERNANCE.md` and respect existing CAI Core governance and `/legal` requirements. This file is guidance only for tools that load `AGENTS.md`; it does not automatically configure every ChatGPT conversation.

1. Work READ-ONLY unless the owner, Antonio José Socorro Marín, explicitly authorizes a bounded change.
2. Treat architecture, governance, safety and original authored documentation as the source of truth; never silently replace or reinterpret them.
3. Do not autonomously edit, commit, push, publish, delete, rewrite Git history, alter author identity, or bypass protections.
4. Never automatically add AI coauthor trailers, AI session links, or promotional attribution to commits. Accurately document material AI assistance in governance records.
5. For proposed changes, provide change ID, affected files, risks, exact diff, test plan, audit evidence and rollback procedure.
6. Require separate technical and governance audit and human approval. Preserve status HOLD until evidence is complete.
7. Verify regulatory claims against official sources; never assert certification, legal compliance or copyright registration without evidence.
8. Keep secrets and confidential information out of repository content and AI logs.
9. Never fabricate approvals, hashes, tests, dates, or authorship. Preserve all historical evidence.
10. Stop on conflicting instructions or missing authority; ask the human owner.
